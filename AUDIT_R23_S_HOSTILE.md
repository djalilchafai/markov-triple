## Mathematical review
1. Hypotheses: `semigroup_nonneg` (Markov.lean:221), `semigroup_le_one` (:368, form `u <=^m 1 -> P u <=^m 1`, exactly `hle`), `semigroup_isSelfAdjoint` (:146) are stated with no finiteness of `T.mu`; `Triple.lean` `ncInf_exists` consumes them directly. `lebesgue_locFin` is an instance by `rfl` rewrite to `volume`. Satisfiable and used.
2. Classic a.e.-to-functional gap (`exists_kernel_of_aeLinear`, AEKernel.lean:62-187): handled correctly. A countable dense additive subgroup `Vg` (Z-span of a countable dense set plus 1) is taken; the a.e. set where additivity on all pairs of `Vg`, the sup bound and positivity hold simultaneously is a countable intersection; a measurable null superset `N` is extracted; for `x notin N` the additive map on `Vg` is extended by `exists_posFunctional` (R15) to a positive continuous linear functional on `C(Y,R)` (continuity from the sup bound), RMK gives a finite measure, `x in N` gets 0 (Kernel measurability via `measurable_of_integrals` and `measurable_of_tendsto_metrizable` over a `Vg`-sequence). Representation for arbitrary `f`: a.e.-Lipschitz bound `|F v - F f| <= ||v - f||` for a sequence in `Vg` (countably many a.e. sets), then uniqueness of limits. `hsmul` is only used for the sup bound, fine. Mass `<= 1` for every `x` (incl. `N`). No gap found.
3. Exhaustion limit (`Exhaustion.lean`): `rr` = measurable representative of `P(1_{K_n} f)`; linear/positive a.e. per `n`; monotone in `n` for `f >= 0` (`tr_le_succ`, `rr_mono`; `hpos` applied to the difference) and bounded by `||f||` (`abs_le_norm_of_aeLinear`), hence a.e. convergent; general `f = f^+ - f^-` (`rr_tendsto_ae`). Limit `F f` chosen measurable (`measurable_limit_of_tendsto_metrizable_ae`); a.e. additivity/homogeneity/positivity/`F 1 <= 1` pass to the limit. Transfer to `OnePoint X` via the measurable embedding and `ae_map_iff`: correct (`G f := extend coe (F f) 0`, measurable). The restricted kernel is `comap coe`, mass <= 1.
   Representation on `C0 cap L2`: `tendsto_tr` shows `1_{K_n} f0 -> u` in `L2` (dominated convergence of the tail; uses `u =^m f0` so `f0` is automatically L2 and uses `extC0 f0 (inf) = 0`); `P` continuous so `P(tr_n) -> P u` in `L2`, an a.e. subsequence, which equals the a.e. limit `F f0 = int f0 dkappa'`; `integral_comap_extC0` removes the point at infinity. Quantifiers match the statement (`f : C0`, `u : Lp`, `u =^m f`). No gap.
4. Sub-invariance (`SubInv.lean`): `int_{K_n} Pu = <1_{K_n}, Pu> = <P 1_{K_n}, u> <= int u` using symmetry and `hle` and `u >= 0`, then monotone convergence; `mu.bind kappa K <= int ofReal(int f dkappa) <= ... <= mu U` via Urysohn `f` (`1_K <= f <= 1_U`, compact support, so in `C0 cap L2 cap L1` since `mu` is finite on compacts), outer regularity for compact `K`, then inner regularity of `bind` (finite on compacts) for all measurable sets. Valid for infinite `mu` (only `C_c` is used, which is in `L2 cap L1`).
5. `ncKernelRepInf : KernelRepresentation T`: fields `kappa`, `subMarkov`, `rep` (KernelRep.lean:37-45), structure unchanged, `rep` for all bounded measurable `MemLp 2` `g`. The extension is `kernelRep_of_dense` (RepExtend.lean:141), which takes `hinv : mu.bind kappa_t <= mu` and a dense `D` of bounded measurable L2 functions (here `ccSet`); `cc_dense` is `C_c` dense in `L2` for `mu` finite on compacts (Mathlib `exists_hasCompactSupport_eLpNorm_sub_le`). The worry "C0 not subset L2" is moot: the test class is `C_c`, contained in both; the dense extension then proceeds by L2 contractivity of `P_t` and of `kappa_t` (Jensen plus sub-invariance), neither needing finiteness of `mu`. Valid.
6. S4 (`Markov.lean`): `u_n` from `exists_nonneg_exhaustion` (in `A0`, bounded, measurable, `0 <= u_n`, `u_n -> 1` a.e. increasing so `u_n <= 1` a.e.); sub-invariance gives `kappa_t(x, {u_n > 1}) = 0` for a.e. `x` (`bind` null implies a.e. null); then `P_t u_n (x) = int u_n dkappa <= kappa(x, X)` (direction correct: `u_n <= 1` kappa-a.e., integral bounded by mass; the proof is not the loose `>=` of the prose but is the same inequality), `P_t u_n(x) -> 1` by `S.conservative`, with `kappa(x,X) <= 1` forces `= 1`. ## Findings
* **LOW-1** `STATEMENTS_R23_S.md` proposed GAPS update says "Riesz-Markov kernel representation: closed for mu finite on compacts (infinite included)". The right scope: closed as a per-time a.e. representation (on `C0 cap L2` abstractly, on bounded measurable L2 for triples), sub-Markov kernels, `mu` locally finite (Radon on a second countable LCH space), sub-invariance needs symmetry; Markov kernels only for `StandardTriple`; only `lebesgueFull` (and the finite `ouDiff` typecheck) exercises it.
