## A. ErgodicL2
Definition: for every `u : Lp 2`, if there are `f_n in A0` with `eLpNorm (f_n - u) 2 -> 0` and `eLpNorm (L f_n) 2 -> 0`, then `u` is a.e. constant.
* Quantification fine: `u` ranges over all of `L^2` (not only classes of `A0`), exactly the kernel of the graph closure `L-bar`. `f_n, L f_n in A0 subset L^2` so no `eLpNorm = infinity` junk. `u` coerced to a function: only a.e. class matters, `eLpNorm` is class-invariant. `c` is allowed to be any real (constants are in the kernel: `f_n = 1`, `L 1 = 0`), so the condition really is "kernel = constants".
* Not trivially true: Bool, L = Gamma = 0 fails (`T2_not_ErgodicL2`, already in Sanity/Ergodic). Not trivially false: **proved** `Sanity.Circle.circle_ErgodicL2 : circleTriple.ErgodicL2` (Audit/ErgodicCircle.lean, ~190 lines). Route: (i) general `Audit.ker_orth`: kernel element `u` satisfies `int u * L g = 0` for all `g in A0` (ibp + symmetry of Gamma; any MarkovTriple); (ii) `e_k = Re fourier k`, `s_k = Im fourier k` lie in A0, `D e_k = -2 pi k s_k`, `D s_k = 2 pi k e_k`, so `L e_k = -(2 pi k)^2 e_k`; (iii) `u` orthogonal to all `e_k, s_k (k>=1)` is a.e. constant by completeness of Mathlib's `fourierBasis`. So `ErgodicL2 /\ Gamma != 0` is jointly satisfiable. (`Sanity.circle_ergodic_statement` can now be discharged by `circle_ErgodicL2` + `.toErgodicΓ`.)
* ErgodicGamma is strictly weaker than ErgodicL2 (paper sketch, not formalised): two copies of the 4-torus with A0 = pairs whose infinite jets agree at one point; Gamma-ergodic, but a point has zero H^2-capacity in R^4, so `(1,0)` is in the closure kernel. Consistent with the docstring ("converse not claimed"); fine.
* Without `esa` (plain MarkovTriple) the closure kernel can be smaller than the kernel of the Friedrichs generator (the one the Hilbert bridge uses). So `ErgodicL2` is the right hypothesis only together with `FullMarkovTriple.esa` (then `generator_graph_eq_closure`). Theorems should be stated for `FullMarkovTriple`. No counterexample found for plain MarkovTriple, just a warning.

## C. CDFull
* Statement: `0<n` and for all `f in A`, a.e. `rho Gamma f f + (1/n).toReal (L f)^2 <= Gamma2 f` with the same `Gamma2` (uses `Gamma f f in A`, `L f in A`, so no junk: all arguments lie in A where the carre-du-champ identity holds). Correct transfer for the interpolation (`P_t f in A` by `semigroup_stable`). `CDFull.toCD` compiles (restriction A0 <= A). It is strictly stronger than CD on A0 in general; for `A = A0` they coincide.
* Consistency: `trivialFull` satisfies it (Gamma = 0). A Gamma != 0 witness is missing. If a circle FullMarkovTriple with `A = A0` existed, CDFull rho n would follow from `circle_CD` for rho <= 0. Building it needs `esa` (doable with the Fourier machinery above: `u` orthogonal to `(1-L)A0` forces all Fourier modes to vanish) and `semigroup_stable`, which quantifies over ALL P with `IsSemigroupOf`: requires showing `P_t e_k = e^{-c t} e_k` (right-derivative-zero argument on `e^{ct} P_t e_k`) and `A0 = span{e_k, s_k}` (product-to-sum). Not done; flagged as the remaining non-vacuity gap for FullMarkovTriple/CDFull.

## D. IsFisherAdmissible
Definition: a.e. `0 < h` and `Gamma h h / h` integrable. Checks (Audit/ErgodicFisher.lean): `fisher_one : IsFisherAdmissible 1 /\ fisherInfo 1 = 0` in every triple (via `L 1 = 0`, `Gamma 1 1 = 0`, both derived from `diffusion` at k=0 + `carre_du_champ`). Units/homogeneity: `I(c h) = c I(h)`, and `Ent` is also 1-homogeneous, so no normalisation `int h = 1` is needed in `Ent h <= (C/2) I(h)`. Integrability is NOT automatic for `h in A0, h > 0` (no Glaeser bound in the abstract setting), so the hypothesis is not redundant. No junk: positivity makes the `x/0 = 0` convention irrelevant (null set).
* D1: `IsFisherAdmissible` does not mention `A0`/`A`; `Gamma` is a free total function off the algebra, so for `h` outside the algebra the number `fisherInfo T h` is meaningless. The docstring leaves membership to the theorem; theorems must add `h in T.A0` (or `A`). 
* D2: on the zero measure every `h` is admissible (`fisher_zero_measure`); harmless.

## F. Erratum F5 and the guard `psi(f) in A0` in `diffusion`
* Fact: the circle instance proves the chain rule for every `f in A0` and every smooth `psi`, ignoring the guard (`diffusion := fun k psi hpsi f hf _ => diffusion_c ...`; `Gc, Lc` are canonical total functions). So the guard is not needed by the circle for the identity itself.
* Do NOT strengthen `MarkovTriple.diffusion` to an unconditional chain rule or to "A0 stable under smooth psi". (1) Unconditional chain rule on a bare structure constrains `Gamma, L` on functions outside `A0`, where they are free junk data: an instance defined by `if f in A0 then ... else 0` would then be rejected for a bookkeeping reason. (2) Stability of A0 breaks the circle and OU: `exp(cos 2 pi x)` is not a trigonometric polynomial (its Fourier coefficients are Bessel values `I_k(1) != 0` for all k), and polynomial algebras are not closed under `exp`. That is why the guard exists.
* The right place is `FullMarkovTriple`: add a field "A is stable under smooth psi (psi(f) in A for f_i in A)", which makes `diffusion_A` effectively unguarded. For the circle one then takes `A := {f : f o coe : R -> R is C^infinity}` (not the trig polynomials) while `A0` and `circleTriple` stay unchanged; `diffusion_c`, `Lc_mul`, `circle_Gamma2` (Sm-only arguments) transfer, so CDFull for rho <= 0 still holds; `semigroup_stable` still fine (P_t of a trig polynomial is a trig polynomial). Exactly what breaks: only the choice `A = A0` for the circle full triple.
* F5 consequence: with A stable and the Hilbert closure results, positivity preservation is derived by the standard argument: for `f in A0`, `psi_eps(f) = sqrt(f^2+eps^2)-eps in A`, `L psi_eps(f) = psi_eps'(f) L f + psi_eps''(f) Gamma(f) in L^2` (bounded psi', psi'', `Gamma f f in A0 subset L^2`), hence `psi_eps(f) in D(L-bar) subset Q` and `E(psi_eps f) <= E(f)`; let eps -> 0, then extend to Q by closure/lower semicontinuity. The step "`F in A`, `F, LF in L^2` => `F in D(L-bar)`" is exactly what is NOT derivable today (G). So F5 is fixable by (A-stability) + (G fix); until then `IsMarkovianForm` stays an explicit hypothesis. I found no counterexample that positivity genuinely fails under the current fields.

## G. [MEDIUM, new: F6] `FullMarkovTriple.ibp_A` is one-sided
`ibp_A` gives `int g * L f = -int Gamma f g` for `f in A` (with `f, Lf in L^2`) and test `g in A0`. Membership `f in D(L-bar) = D(L*)` needs the other integration by parts `int f * L g = -int Gamma g f` (equivalently, with `carre_du_champ_A`, `int L(f g) = 0`), i.e. a test function `f in A` in the second slot, and `ibp_A` cannot be applied to `f*g` because `f*g, L(f*g)` need not be in `L^2` (`f in L^2`, `Lg` only in all `L^p`, p<infinity). The docstring ("by `esa` such f lie in the domain of the closure of L") is therefore unsupported by the fields. I found neither a derivation nor a counterexample (in nice 1-D examples the boundary terms vanish). Fix: add the symmetric identity as a field, or state `f in A, f, Lf in L^2 => ⟨f, L g⟩ = ⟨L f, g⟩ for g in A0` (L^2 limit-point condition). It is needed by the Bakry-Emery proof and by F5.
